Three ways to answer

Each version adds one idea on top of the last. The answers on this page come from v3 with the transcripts as the source.

LLM alone
The model's memory only. No transcripts.
v1 · Vector search
Finds the 8 scenes closest in meaning to your question.
v2 · + Keywords and SQL
Rewrites the question, also matches exact words, and can count with SQL.
v3 · + Relationship graph
Adds facts extracted from every episode (who dated whom, what happened, when).

Dev mode lets you pick the version and which answers to compute (RAG, LLM, LLM + RAG) and compare them.
